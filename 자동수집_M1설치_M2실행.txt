====================================================================
심사점검표 자동수집 매크로 — 즐겨찾기 2개 세트 (M1 설치 + M2 실행)
  = 별표 친 선행건만 골라 점검표 팝업을 자동으로 열고 → 수집 → 클립보드
====================================================================

■ 무엇을 하나
- 심사점검표 화면(타인선출원/본인선출원/본인선등록/타인선등록)에서
  드롭다운으로 별표(흰별표/까만별표/만료별표 아무거나)를 고른 행만 골라:
  1) 그 행의 [심사점검표] 버튼을 자동으로 눌러 팝업을 열고
  2) 셀프캡처 6판과 같은 수집(신형 DOM + 구형 GetFieldTextData)을 하고
  3) 팝업을 닫고 다음 별표 건으로 진행
  4) 한 건 끝날 때마다 클립보드에 바로 반영 → 뷰어(v8.3)를 열어두면
     붙여넣기 없이 저절로 화면에 쌓이고, 끝나면 결과 요약까지 표시됨
- '안고르기' 상태(빈 칸)인 행은 건드리지 않음
- 국제상표(6자리 국제등록번호, [심사점검표] 단추 없는 행)도 자동 처리:
  번호 링크 클릭 → 출원서조회 팝업 → 그 안의 [심사점검표] 단추를
  알아서 찾아 클릭 → 구형 편집기 내용([클립] 4종)까지 수집 후
  팝업 2개를 모두 닫음. 별표만 골라두면 국내/국제 구분 불필요

■ 설치
- 즐겨찾기 2개를 만들어 URL에 아래 [M1 코드], [M2 코드]를 각각 넣기
  (한 개로 합치면 이 PC의 길이 제한(약 2,963자)에 걸려서 2개로 나눔)
  · M1 = 수집 엔진 설치 (v2·2,893자)
  · M2 = 별표 건 스캔 + 자동 실행 (v5·국제지원·2,726자)

■ 사용법 (자동 연동 — 붙여넣기 불필요)
0. 뷰어(점검표뷰어_v8.3.html)를 IE로 미리 열어 둔다
   → '자동 감지'가 저절로 켜짐 (권한 확인창이 뜨면 [허용])
1. 심사점검표 화면에서 별표 드롭다운을 평소처럼 골라 놓기
2. 그 창에서 [M1] 클릭 → 알림 'M1'
3. 이어서 [M2] 클릭 → '○건 수집?' 확인창 → [확인]
4. 팝업이 저절로 열렸다 닫혔다 하며 진행됨 (건당 약 5~25초)
   → 한 건 끝날 때마다 뷰어 화면에 실시간으로 쌓임
   ※ 진행 중 내부망 PC는 건드리지 말 것 (외부망 PC는 자유)
5. 끝나면 알림 'OK 성공수/전체수' + 뷰어 상단에 초록 배너로 결과 요약
   (총 건수 / ★유사 표시 건수 / 심사관 의견 건수 / 등록·거절 결정 수)
6. 실패 건이 있으면 알림에 'F:번호' 로 표시됨
   → 그 건만 평소처럼 [심사점검표] 눌러서 셀프캡처로 수동 보완

※ 뷰어를 안 열어둔 경우: 예전처럼 뷰어 입력칸에 Ctrl+V 한 뒤
  [붙여넣은 내용 정리하기]를 눌러도 똑같이 동작함

■ 알림/오류 뜻
- 'M1?' : M1을 안 누르고 M2부터 누름 → M1 먼저
- 'NF'  : 심사점검표 내용 화면을 못 찾음 → 점검표가 보이는 창에서 실행
- '0'   : 별표 고른 행이 하나도 없음
- 'RUN' : 이미 실행 중 (끝날 때까지 대기)
- 'X'   : 클립보드 기록 실패

■ 주의
- 화면에 보이는 페이지의 별표 건만 수집됨 ([이전]/[다음] 페이지는
  페이지 넘긴 뒤 M2를 다시 누르면 됨. M1은 창마다 한 번이면 충분)
- 팝업을 한 번에 하나만 열고 닫으므로 서버 부하는 수동 클릭과 동일
- 팝업이 20초 안에 안 열리면 실패 처리. 열린 뒤에는 내용이 잡힐
  때까지 1초 간격으로 최대 28초 재시도 (구형 편집기 로딩 대비)
- 국제건은 팝업을 두 단계 거치므로 건당 시간이 더 걸림(약 10~40초).
  편집기 내용이 끝내 안 잡히면 화면 내용만이라도 수집하고 넘어감
- 수집된 점검표에는 팝업 주소의 출원번호가 자동 기입되므로,
  뷰어 요약표에 번호가 (번호미상) 대신 제대로 표시됨
- 뷰어가 같은 건을 두 번 담지 않도록 중복 검사를 하므로, 중간 저장이
  여러 번 반영돼도 건수는 정확함
- 매크로가 도는 동안 내부망 PC에서 Ctrl+C를 누르면 중간 결과가 지워짐
  (외부망 PC에서의 복사는 무관)

■ 동작 원리 요약 (참고)
- 정찰 결과, 점검표 내용 프레임(getProcExmntCtbstCont.do)은 일반 표라서
  각 행의 별표 드롭다운(첫 항목='안고르기')이 선택돼 있는지로 판별
- 별표 행에서 글자가 '심사점검표'인 버튼을 찾아 코드로 대신 클릭
  (행 기준으로 딱 1개일 때만 클릭 → 엉뚱한 버튼 누를 일 없음)
- window.open 가로채기(v6.7 방식)로 팝업 손잡이를 잡고,
  본문이 채워질 때까지 기다렸다가(최대 20초) 3초 더 안정 후 수집
- 수집 결과는 셀프캡처와 동일한 [팝업캡처]/[클립] 표식 형식이라
  뷰어의 [붙여넣은 내용 정리하기]가 그대로 인식함
