■ 4판의 문제 (덤프 분석으로 확인)
- 대체 수집(innerText)이 긁어온 6만 자짜리 "텍스트"는 문서가 아니라
  페이지의 스크립트 소스코드였음 → 붙여넣으면 코드 덩어리만 보임

■ 5판의 해법 — 특허넷 자체 코드에서 찾아낸 정식 추출 API 사용
- 덤프에 담긴 특허넷 코드가 편집기를 다루는 방법이 그대로 있었음:
  HwpRemoteCtrl.GetFieldTextData("필드명")
- 문서의 박스 4개 = 필드 4개:
  SRCH_RSLT(검색결과) / EXMN_CONT(심사내용) /
  RMKS_SMRY_TL(의견요약) / EXMNR_DCSN_CMNT_TL(판단의견)
- 5판은 껍데기를 정밀 수집(스크립트 제외)하고, 위 4개 필드를
  API로 직접 뽑아 [클립] 조각으로 자동 첨부
  → 박스 클릭/Ctrl+A/C 자체가 불필요

■ 사용
1. 심사점검표 팝업 창 바깥 영역 클릭 → Ctrl+I → 셀프캡처
2. 알림 'COPY5 글자수 F프레임수 H필드수'
   - H3~H4 = 성공! (내용 있는 박스 수만큼)
   - H0 = 필드 추출 실패 (그대로 알려주세요)
3. 메인 창 [CLIP] → +1 → [OUT] → 뷰어
   → 카드에 검색결과/심사내용/판단의견 섹션이 자동 정리됨
