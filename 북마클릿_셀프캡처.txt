셀프캡처 — 점검표 창 안에서 직접 실행하는 보조 북마클릿 (1,571자)
====================================================================

■ 용도
- 어떤 방식으로 열린 창이든(2차 팝업, 모달 등) 그 창 "자신"의 화면을
  덤프해서 [팝업캡처] 표식과 함께 클립보드에 담음
- 메인 패널의 [CLIP]을 누르면 새 건으로 들어감 (v6.5 필수)
- 창 추적이 안 되는 국제등록상표 심사점검표용 우회로

■ 설치
- "새" 즐겨찾기를 하나 만들어(이름: 셀프캡처) URL에 아래 코드
- 메인 북마클릿(v6.5)과 별개로 공존

■ 사용
1. 심사점검표 창 안에서 Ctrl+I → [셀프캡처] 클릭
2. 'COPY 숫자' 알림 = 성공 (EMPTY면 창 내용이 너무 적은 것)
3. 메인 창으로 가서 [CLIP] → 건수 +1 확인
4. 이후 기존과 동일: [OUT] → 뷰어 붙여넣기
