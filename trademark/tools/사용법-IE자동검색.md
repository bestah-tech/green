# IE 자동 검색 (search.vbs) 사용법 — 초안 v1

크롬이 검색시스템에 못 들어가는 동안, **IE를 밖에서 조종해 검색을 자동 실행**하는 스크립트입니다.
윈도우 내장 기능(VBScript)만 사용하므로 별도 프로그램 설치가 없습니다.

> ⚠️ 처음 한 번은 시험 실행입니다. 결과 대기 시간·화면 이름이 실제와 다르면 스크립트 상단 설정을 조정해야 합니다 (결과를 개발자에게 알려주면 맞춰 드립니다).
> ⚠️ 내부망에서 스크립트(.vbs) 실행이 보안 규정상 허용되는지 먼저 확인하세요.

## 흐름 한눈에

```
크롬 TRADEMARK                     IE                          크롬 TRADEMARK
검색식 내보내기(.txt) ──► search.vbs 더블클릭 ──► TmResults.txt ──► 붙여넣기 수집
(사이드패널)               (검색 자동 반복)        (결과 모음)       (후보 자동 등록)
```

## 준비 (한 번만)

1. `tools/search.vbs` 를 바탕화면 등 한 폴더에 복사합니다.
2. 메모장으로 열어 상단의 `APPL_NO = ""` 에 심사 중인 **출원번호(하이픈 없이)** 를 넣습니다.
   - 예: `APPL_NO = "4020250012345"`

## 매번 실행 순서

1. **IE**: 평소처럼 심사점검표에서 검색시스템(스마트검색) 창을 엽니다 (로그인 상태 유지).
2. **크롬**: TRADEMARK 사이드패널 → 승인 2 검색식 → **[검색식 내보내기 (.txt)]** → 내려받은 `TmQueries.txt` 를 search.vbs 와 **같은 폴더**로 옮깁니다.
3. `search.vbs` **더블클릭** → IE 창에서 검색이 차례로 자동 실행되고, 끝나면 완료 알림이 뜹니다.
4. 같은 폴더의 `TmResults.txt` 를 열어 **전체 복사(Ctrl+A, Ctrl+C)**.
5. **크롬**: 사이드패널 ① 카드의 붙여넣기 칸에 붙여넣고 → **[붙여넣은 텍스트에서 후보 추출]** → 체크 → 저장 → 유사도 평가.

## 스크립트가 하는 일 (원리)

- 이미 열려 있는 IE 창 중 검색시스템(`/ts/` 또는 `Kipo.ts`) 창을 찾아 붙습니다 → **로그인 세션 그대로 사용**
- `TmQueries.txt` 의 각 줄(라벨 / TmName 검색식 / ClassCd 유사군코드)로
  유사질의어 검색 URL(`mainSimilarSrch.do`)을 만들어 셸의 `content_iframe` 에 로드합니다
- 로딩이 끝나면 결과 화면의 텍스트를 통째로 `TmResults.txt` 에 이어 붙입니다

## 문제 해결

| 증상 | 조치 |
|---|---|
| "Search-system IE window not found" | IE에서 검색시스템 창을 먼저 열고 다시 실행 |
| 결과가 "(no result text)" | 스크립트 상단 `LOAD_WAIT_MS` 를 4000~6000 으로 늘려보기 |
| 결과가 목록이 아니라 오류/로그인 화면 텍스트 | 그 텍스트 그대로 개발자에게 전달 (URL 파라미터 보정 필요) |
| .vbs 더블클릭이 막혀 있음 | 보안 정책으로 차단된 것 — 전산 확인 필요. 이 경우 기존 수동 복사 방식 사용 |
