## 1. 프로젝트 개요

- **TRADEMARK**: 상표 심사지원 크롬 확장(MV3). K-SUITE(특허심사용 내부 도구)의 구조를 상표심사에 옮긴 것
- 원 지시서: "상표 심사지원 크롬 확장프로그램 개발 지시서" (5모듈·승인 게이트·버전 체인·근거 제한 원칙)
- **빌드 없음** — 폴더 그대로 "압축해제된 확장 프로그램 로드". 외부 CDN·서버 없음. 데이터는 IndexedDB(브라우저 안)에만

## 5. 사용자와의 약속·맥락

- 매 업데이트마다 **"오늘의 코드 설명"** 한 단락(학습용)을 붙여주기로 함 — 사용자는 동기(K-SUITE 개발자)를 넘어서고 싶어 함. 격려+실질 학습 유지
- kgim 사례: 접두 K=Korea 못 잡음 → 교정지시 텍스트 제안해 둠 (홈 화면에서 mark_structure·oa33_analyze에 저장하라고 안내함). 이런 실무 관행은 교정지시로 누적하는 게 방침
- 배포 루틴: 커밋·푸시 → `zip -r -P "tm2026!" TRADEMARK.zip trademark` → SendUserFile로 전달 → 사용자는 내부망 반입 후 확장 새로고침(⟳)
- 개인 자산 파일(상용구 HTML·코퍼스 txt·의통서 SPEC md)은 저장소에 커밋하지 않음. 새 세션에서 필요하면 사용자에게 재업로드 요청
