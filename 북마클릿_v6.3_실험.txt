====================================================================
v6.3 (실험) — 구형 HWP 편집기 본문 자동 추출 시도
====================================================================

■ 무엇이 다른가 (v6.2 대비)
- [IN]을 누를 때 팝업 안의 ActiveX 개체(구형 HWP 편집기)를 만나면
  HWP 자동화 API(GetTextFile)로 문서 전체 텍스트를 뽑아
  [클립] 조각으로 자동 첨부 시도
- 성공하면: 구형도 [IN] 한 번으로 끝 (박스 클릭/Ctrl+A/C, CLIP 불필요)
- 실패하면(보안 차단 등): 조용히 무시됨 → 기존처럼 CLIP 방식 사용
- v6.2의 [구분선] 기능 포함

■ 주의
- 코드가 3,202자로 김. 즐겨찾기에 붙여넣은 뒤 속성에서
  맨 끝이 })(); 로 끝나는지 반드시 확인. 잘렸으면 v6.2로 복귀.
- 실행 시 'READY v6.3' 알림이 뜨면 설치 성공.
- 구형 팝업에서 [IN] 후 [OUT] → 뷰어에 붙여 검색결과/심사내용이
  자동으로 나오면 성공. 안 나오면 이 PC에서는 API가 차단된 것이므로
  v6.2 + 통복사(아래) 방식을 쓰면 됨.

■ 코드 변경 없이 쓰는 우회법 (v6.1/v6.2에서도 가능)
  구형 팝업에서 커서를 기재 박스 "바깥"(【검색결과】 제목 글자 옆)에
  찍고 Ctrl+A → Ctrl+C → [CLIP] 한 번.
  또는 편집기 메뉴 [편집(E)] → [모두 선택] → 복사 → [CLIP].
  → 문서 전체가 한 번에 담기고, 뷰어 v8이 【검색결과】【심사내용】
    【의견요약】【판단의견】 표제를 알아서 나눠 정리함.
